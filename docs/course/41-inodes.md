# 第 41 课：把磁盘块组织成文件

状态：待开始。前置：[第 40 课](40-format.md)。分 A、B 两次，每次 45～60 分钟。

## A 次：根据偏移读取

1. 实现 inode 按号读取、类型验证和直接块查询；文件偏移除以 4096 得到块索引，余数是块内偏移。
2. 读取量取请求长度与 EOF 之前长度的较小者；位置在 EOF 返回 0，不能读到其他文件内容。
3. 跨块分段读取，普通文件已声明大小内缺少块指针视为格式错误，不当作已支持稀疏文件。
4. 使用宿主机预置的 4097 字节模式验证首尾和跨块读取，另测空文件、精确整块和 EOF。

## B 次：扩展与空间不足

1. 第一版只允许覆盖现有字节或从 EOF 追加，不允许越过 EOF 造洞；每次用户写入最多沿用 256 字节限制。
2. 写入前计算所需新块与最大文件限制，先预留所需资源，分配失败撤销本次新资源并保持文件原状。
3. 新块清零后修改内容，再更新 inode 指针与大小并标脏。正常内存操作失败可回滚；已经发生设备 I/O 错误则进入明确错误模式，不声称磁盘已事务回滚。
4. 超过 12 个直接块返回文件过大错误；空间不足不应写出指向未分配块的 inode。
5. 完成写入后 sync，重启核对大小和全部字节；不要仅看缓存里的内容。

每次约 15 分钟寻址图解、25 分钟实验、15 分钟复盘。崩溃发生在数据与 inode 更新之间的一致性问题留给下一阶段。

## 常见问题与验收

| 现象 | 先检查 |
| --- | --- |
| 跨块最后一字节错 | 分段长度和块内偏移计算 |
| EOF 后读出旧数据 | 是否按 inode.size 限制长度 |
| 文件扩展后其他文件变化 | 分配唯一性与块指针是否正确 |

- [ ] 空、整块、跨块、EOF 与最大长度检查通过。
- [ ] 资源不足不留下非法块引用，重启后内容正确。
