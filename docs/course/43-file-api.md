# 第 43 课：在 shell 中使用磁盘文件

状态：待开始。前置：[第 42 课](42-directories.md)。分 A、B、C 三次，每次 45～60 分钟。

## A 次：文件描述符接口

保留旧调用 1～25，read/write/close/dup2 继续使用 9～12，并按对象类型分发。新增课程调用：

| 号 | 接口 | 约定 |
| --- | --- | --- |
| 26 | `open(path,len,flags)` | flags 掩码：`READ=0x1`、`WRITE=0x2`、`CREATE=0x4`；至少包含 READ 或 WRITE；返回 fd |
| 27 | `seek(fd,offset)` | 普通文件内绝对偏移，范围 0～size；返回新偏移 |
| 28 | `mkdir(path,len)` | 创建目录，成功 0 |
| 29 | `readdir(fd,buf,len)` | 只对目录，逐项输出固定 64 字节记录；不足一项返回 -2，EOF 为 0 |
| 30 | `fsync(fd)` | 校验文件/目录 fd 后执行第一版全局 sync，成功 0 |
| 31 | `exec_path(path,len)` | 从普通文件加载程序，成功不返回旧程序 |
| 32 | `sync()` | 写回全部脏数据与元数据并 flush，成功 0 |

这里的 `0x1/0x2/0x4` 是位掩码的数值，不是“第 1、2、4 位”的编号。组合例如 `READ | CREATE = 0x5`。未知 flag 位直接返回非法参数，不能静默忽略。

新错误码：-11 文件不存在；-12 名称已存在；-13 类型不匹配；-14 I/O 或格式错误；-15 文件或目录过大。旧 -2/-3/-4/-7 分别继续表示非法参数、用户地址、资源不足和 fd/方向错误。

1. 增加全局打开文件对象，保存 inode、权限、偏移与引用数。每次 open 创建独立偏移；fork 和 dup2 共享同一打开对象及偏移，线程共享进程 fd 表。
2. 沿用用户范围验证和内核缓冲复制。read 的用户写回范围必须先验证，失败不推进偏移；write 先复制输入再修改文件。
3. read/write 最大 256 字节，目录通过 readdir 读取而非普通 write；open 目录只允许读。seek 不对管道生效。
4. 多线程调用用当前单核同步内核路径串行处理；原 fd 使用中规则保留。close 减引用，但不代表 flush。

## B 次：从磁盘加载受控程序

1. 先定义小型 NEX1 教学镜像头：版本、头长度、代码/数据长度、BSS 长度、入口偏移与校验信息；字段宽度和端序另写入格式文档。
2. 宿主机工具把已验证可重定位的用户汇编样例打包为文件，通过离线生成器放到 `/bin/hello`；文件不超过本阶段 48 KiB 上限。这不是通用 ELF 加载器。
3. exec_path 校验类型、头大小、文件长度、加法溢出、入口落在代码内、段权限、地址重叠和总内存上限，再构建候选地址空间。
4. 复用第 24 课提交机制：PID 与描述符保留，候选成功后切换并释放旧映像；失败返回错误，旧程序仍可运行。多线程限制按第六阶段保留。
5. 从文件完整复制映像后解除加载资源；并发线程不能在加载中改出不一致快照，第一版同步串行路径保证复制期间不切走。

## C 次：shell 与两次启动验收

1. 扩展用户 shell 的有限解析，支持空格分隔的简单文件命令：`ls /`、`mkdir /notes`、`touch /notes/a`、`write /notes/a hello`、`cat /notes/a`、`sync`，先不支持引号或任意复杂参数。
2. 文件操作可由用户 shell 内建通过系统调用完成；旧无参数 cat 仍保留管道字节流行为，避免破坏 `hello | cat`。
3. 输入绝对程序路径时，子进程调用 exec_path，其他流程复用 fork/wait。先只执行无参数磁盘程序，不暗中依赖尚未实现的 argv 运行时。
4. 第一轮创建目录和文件、写入、sync；退出 QEMU。第二轮使用同一镜像读取并执行 `/bin/hello`，中间禁止 mkfs。
5. `tests/storage.sh` 分开“新建测试盘”“写入启动”“读取启动”，验证明确完成标记、内容、错误和超时；失败保留镜像供排查。
