# 第 23 课：TLB 未命中和缺页不是一回事

状态：待开始。前置：[第 22 课](22-page-faults.md)。预计 45～60 分钟，两个模拟可拆开练。

## 目标与阅读

阅读 OSTEP 第 19、21、22 章。TLB 缓存地址转换；页面替换决定驻留空间不足时移走哪一页。模拟“调入页面”不代表内核已经接上交换磁盘。[官方章节入口](https://pages.cs.wisc.edu/~remzi/OSTEP/)

## 实验一：先只模拟 TLB（15 分钟）

计划创建宿主机脚本 `experiments/vm.py`，设置固定容量 TLB 和有效页表。使用页号序列 `1,2,1,3,1,2`，统计转换缓存命中与软件查表次数。

1. TLB 未命中时查询页表：已有合法驻留映射则填入缓存，不算缺页。
2. 页表未映射或权限拒绝才报告相应失败；不能通过增加 TLB 容量修复权限错误。
3. 模拟两个进程同一虚拟页对应不同物理页，使用“切换清空 TLB”或带地址空间标识的键，观察错误复用会得到什么结果。

模拟查表次数不是 QEMU 的真实硬件性能计数，不据此宣称测出了处理器 TLB 速度。

## 实验二：页面替换（25 分钟）

设置固定页框数，分别实现 FIFO、LRU 和需要预知未来的 OPT，逐步输出命中、缺页、淘汰页与驻留集合。平局按固定规则处理。

用序列 `1,2,3,4,1,2,5,1,2,3,4,5`，先手算 FIFO：3 个页框应缺页 9 次，4 个页框为 10 次。它展示更多页框也可能使 FIFO 表现变差。

再运行 LRU、OPT，与 FIFO 比较；OPT 是具有未来信息的对照，不是当前内核可直接使用的预测能力。LRU 命中时更新最近使用顺序，FIFO 命中不改变入队顺序。

验证空序列、单页重复、全不同页；页框数为零或负数直接拒绝。所有访问数应等于命中数加缺页数，驻留集合大小不能超过容量。

## 常见问题与验收（10 分钟）

| 现象 | 先检查 |
| --- | --- |
| TLB 未命中都算磁盘读取 | 是否把转换缓存与驻留页混成一层 |
| FIFO 和 LRU 总是一样 | 是否错误地在 FIFO 命中时更新队列 |
| OPT 淘汰近期要用的页 | 是否选了最近而不是最远的下一次访问 |
