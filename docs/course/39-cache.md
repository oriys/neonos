# 第 39 课：把常用磁盘块留在内存里

状态：待开始。前置：[第 38 课](38-block-write.md)。分 A、B 两次，每次 45～60 分钟。

## 目标与设计

使用 8 个固定缓存槽，每槽保存一个 4 KiB 文件系统块。统一文件系统块到设备扇区的转换，缓存键包含设备身份与块号。

## A 次：查询与替换

1. 定义 valid、dirty、引用计数、键和替换顺序；同一块最多一个有效副本。
2. 命中返回受控访问句柄，未命中才读设备；有引用的槽不可驱逐。
3. 所有槽都被引用时明确返回忙或资源不足，不能覆盖仍在使用的缓冲区。
4. 统计底层读取次数：重复访问同一块应命中，循环访问超过容量的块触发替换。

## B 次：脏块和错误

1. 修改必须显式标 dirty。驱逐脏块前等待写回成功，失败保留键、数据与脏状态。
2. 区分“脏块已经写到设备”和“设备已 flush”；全部缓存写完后仍须执行 flush 才完成 sync。
3. 使用单核同步 I/O 串行化第一版文件系统操作，不拿用户睡眠锁保护内核驱动，也不跨调度保留缓存引用。
4. 无文件系统读写路径可绕过缓存修改同一磁盘区域；宿主机离线修改镜像后必须重新启动或清理缓存状态。
5. 在脏驱逐时注入错误，验证下一次读取不会把槽误认成另一个块。

## 常见问题与验收

| 现象 | 先检查 |
| --- | --- |
| 改过的块偶尔变回旧内容 | 是否有多个副本或绕过缓存写盘 |
| 写回失败后数据消失 | 是否提前清 dirty 或替换键 |
| 缓存越来越满 | 句柄引用是否按路径归还 |

- [ ] 命中计数、驱逐、引用占用与写回失败正确。
- [ ] sync 的缓存与设备两层状态清楚。
