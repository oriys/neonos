# 第 36 课：先准备一块实验磁盘

状态：待开始。前置：[第六阶段](stage-06.md)。预计 45～60 分钟。

## 目标与阅读

阅读 OSTEP 第 36～38 章的设备、磁盘和 RAID 概念，首轮重点看请求与完成。结合 [QEMU virt 平台文档](https://www.qemu.org/docs/master/system/riscv/virt.html) 为当前机器配置一个 virtio 块设备。

## 分步实验

1. 在项目专用输出目录建立全新的 16 MiB raw 镜像，记录绝对路径、大小和创建方式，工具默认拒绝覆盖已有文件。不对宿主机真实磁盘或用户其他文件做格式化。
2. 写入已知位置标记，例如设备扇区 64 的 `neonos disk probe`，另外记录该扇区预期字节和校验值。这个探针镜像与第 40 课文件系统镜像分开创建。
3. 给 QEMU 显式指定 raw 格式与 virtio-blk-device 后端；核对现代 virtio-mmio 配置。磁盘只允许一个 QEMU 实例写入，宿主机修改前先停机。
4. 导出当前实验机设备树或读取相应配置，记录 MMIO 区域和设备身份。不能假设任意 virtio MMIO 槽都挂着磁盘。
5. 区分设备扇区与文件系统块：扇区 64 的偏移是 32768 字节；文件系统块 8 对应扇区 64～71。

时间建议：10 分钟概念、30 分钟镜像与配置、15 分钟核对。新增磁盘配置先作为显式测试入口，不破坏已有无磁盘启动检查。

## 常见问题与验收

| 现象 | 先检查 |
| --- | --- |
| 镜像格式识别不确定 | 是否显式指定 raw |
| 设备树有槽但读不到磁盘 | 是否真的连接块设备后端 |
| 标记偏移不对 | 是否把 512 字节扇区当作 4 KiB 块 |

- [ ] 可重复创建独立探针盘，大小、偏移与标记可核对。
- [ ] 磁盘配置有独立入口，设备发现依据已记录。
