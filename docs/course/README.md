# neonos × OSTEP 学习路线

目标：通过 Rust + RISC-V 教学内核，理解并实现操作系统的虚拟化、并发和持久化核心机制。

教材入口：[Operating Systems: Three Easy Pieces 官方免费章节](https://pages.cs.wisc.edu/~remzi/OSTEP/)。章节对应按官网目录核对于 2026-09-06。本路线是 neonos 的配套实验设计，不是书中的官方内核实现教程；RISC-V、Rust 和设备实现细节需要额外的专项学习。

## 每课怎么学

1. 用一个具体问题引入，只介绍本课需要的术语。
2. 阅读指定章节的小节；先抓住问题和例子，再回看细节。
3. 先预测运行结果，再看现有代码并做最小修改。
4. 运行实验，比较预测和实际结果；涉及错误处理时加入一个失败场景。
5. 用自己的话解释现象，记录结果与疑问。

Rust 的引用、裸指针、trait、宏、所有权随实验补充。第一次遇到汇编，逐条解释寄存器和指令。开始新功能前，先确认上一课的代码能够运行。

## 第一轮边界与完成标准

第一轮面向 QEMU `virt`、单核 RISC-V、串口交互。先使用固定容量的数据结构，逐步加入堆分配。用户程序最初内嵌在内核镜像中，文件系统完成后再从磁盘加载。

完成后应能演示：启动 shell；运行多个用户程序；定时切换任务；隔离进程地址空间；通过同步避免竞争；创建并读取文件；重启后读取原内容；在指定故障点中断写入后恢复文件系统。

每个里程碑保存可复现的操作、预期输出和必要的回归检查。只有功能实际验证、且能够解释其工作方式，才算完成。

## 47 个学习单元

所有课程初始状态均为待开始。章节数字指 OSTEP 章节；“预备”表示项目所需的补充内容。

### A. 内核基础：01～05

阅读：第 2 章 Introduction；其余为 Rust、链接与 RISC-V 预备知识。

| 课次 | 问题与实验 | 验收 |
| --- | --- | --- |
| 01 | 从启动入口追踪到串口，增加一行欢迎语 | 保留 `Hello kernel`，新输出可见，能复述启动路线 |
| 02 | 提取串口模块，按需学习格式化和宏，实现打印工具 | 能输出字符串、整数和十六进制地址 |

## 书中其他主题如何安排

第一轮不会把所有章节都变成内核功能。第 10 章多核调度、第 21 章真实换页、第 23 章完整虚拟内存系统留到进阶；分段、彩票调度、页面替换先通过模拟学习。磁盘调度、RAID、FFS、LFS、SSD 和数据完整性安排阅读与比较实验；分布式文件系统、安全与虚拟机等内容作为后续专题。

进阶实现顺序建议：写时复制 → 按需分配与真实换页 → 多核同步与调度 → 更完整的文件系统和缓存策略。第一轮结束后，根据兴趣再安排具体课程。
